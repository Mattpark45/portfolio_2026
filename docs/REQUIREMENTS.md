# 요구사항 · 운영 기준 (CLAUDE.md·AGENTS.md가 참조하는 원본)

기준 업무문서: Notion Master, P04, P06, 재무X레이 매뉴얼의 "Digital Branch Conversion Pack 01"(2026-11-26). 구조와 로드맵은 `docs/ARCHITECTURE.md`.

## 금융광고 미심의 상태 표현 규칙 (자동 검사: tests/check.mjs)
1. 금융상품명·상품 종류(보험·펀드·변액·연금보험 등)를 쓰지 않는다.
2. 가입 권유, 수익·절세·혜택·결과의 약속이나 수치를 쓰지 않는다. "무료", "최저가"도 쓰지 않는다. 비용은 "사전 안내·합의" 원칙만 밝힌다.
3. 소속 GA명, 금융 전산·서비스명(A-LINK·A-LINE·A-CARE·메디빅뱅), 과거 소속 금융사명을 쓰지 않는다.
4. 개인 상담은 "상담 일정 요청"까지만. 상품 관련 절차는 "고객이 원할 때 소속 회사의 승인된 절차와 시스템으로만"이라고만 쓴다.
5. 기업 상담은 금융상품과 무관하며 가입이 조건이 아님을 밝힌다.
6. 경력·사례는 당시 기준임을 밝히고, 근거가 확인되지 않은 수상·인증·직함은 쓰거나 링크하지 않는다.
→ 심의를 받으면 승인 범위에 맞춰 이 규칙과 검사 목록을 조정한다(사용자 지시로만).

## 확인된 사실 (공개 문구 기준)
- 베트남: 거주가 아니라 **수출 프로젝트 약 10년 참여**(2026-11-27 사용자 확인). "베트남 16년 생활" 표현 금지.
- 연구소 16개 협업 분야는 연구소 공통 네트워크이며 협력사명은 연구소 허락 전 비공개.
- 소속 GA명 표기는 광고 심의 후. 그 전에는 "소속 회사의 승인된 업무환경"으로만 쓴다.

## 개인정보
- 정보를 전송하는 입력 양식, 방문 분석·추적 도구를 두지 않는다(승인 전).
- 상담 준비 질문은 브라우저 안에서만 동작한다. 저장소(localStorage 등)·네트워크 전송 API 사용 금지(정적 검사 + E2E로 확인).
- 건강·인증·계좌·계약 상세 정보를 보내지 말라는 안내를 유지한다. 개인정보 안내는 전문가 검토 전 초안.

## 기술
- 공개 파일은 `site/`에만 둔다. 문서·시험·지침은 배포되지 않는다.
- 내부 링크는 루트 기준으로 써도 되며 `npm run layout`이 상대경로로 바꾼다(검사가 강제).
- 인라인 스크립트 금지(`site/_headers` CSP). 외부 자원은 Pretendard 폰트 CDN만.
- 모든 변경은 브랜치·PR, `npm test` 통과 후 사용자 승인으로 배포한다.
