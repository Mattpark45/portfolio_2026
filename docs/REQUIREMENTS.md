## Phase 1 범위 (현재)
- 브랜드·개인/기업 진입 동선·소개·상담 일정 요청·개인정보 안내

- 무료 주소(Cloudflare Pages) 사용, 유료 서비스 도입 없음

## 금융광고 미심의 상태 표현 규칙 (자동 검사: tests/check.mjs)
1. 금융상품명·상품 종류(보험·펀드·변액·연금보험 등)를 쓰지 않는다.
2. 가입 권유, 수익·절세·혜택·결과의 약속이나 수치 제시를 하지 않는다. "무료", "최저가"도 쓰지 않는다.
3. 소속 GA명, 금융 전산·서비스명(A-LINK·A-LINE·A-CARE·메디빅뱅), 과거 소속 금융사명을 쓰지 않는다.
4. 개인 페이지는 "상담 일정 요청"까지만 둔다. 상품 안내는 상담에서 소속 회사의 승인된 절차로만 한다.
5. 기업 상담은 금융상품과 독립적이며, 가입이 서비스 조건이 아님을 명시한다.
6. 실적·사례는 당시 담당 업무 기준임을 밝히고, 근거 링크가 확인되지 않은 수상·인증·직함은 링크하지 않는다.
→ 심의를 받으면 이 규칙과 검사 목록을 승인 범위에 맞춰 조정한다.

## 개인정보
- 사이트에 입력 양식을 두지 않는다(수집 경로가 승인되기 전까지). 방문 분석 도구도 아직 넣지 않는다.
- 건강·인증·계좌·계약 상세 정보를 보내지 말라는 안내를 유지한다.
- 개인정보 처리 안내는 초안이며 전문가 검토가 필요하다.

## 기술
- 공개 파일은 `public/`에만 둔다(문서·시험·지침은 배포되지 않음).
- 정적 HTML/CSS/JS, 외부 의존성은 Pretendard 폰트 CDN뿐. 인라인 스크립트 금지(`_headers`의 CSP).
- 머리글·바닥글은 `partials/`가 원본이며 `scripts/sync_layout.py`로 각 페이지에 복사한다.
- 모든 변경은 브랜치와 PR로 하며, `npm test` 통과가 병합 조건이다. main 병합 = 운영 배포이므로 사용자 승인 후에만 한다.
